# Demo video storyboard (60–90 s)

**Goal:** Show evidence-backed review—not a chatbot verdict.

1. **Hook (5 s)** — “Scholarship packet, one missing doc can disqualify you.”
2. **Upload (15 s)** — Requirements PDF + Meridian demo application PDFs.
3. **Analyze (10 s)** — OpenRouter or Ollama; show real progress stages.
4. **Payoff (25 s)** — Open **Evidence inspector**: transcript needs review OR contradiction with quoted dates; show instruction quote + evidence excerpt + page.
5. **Action plan + export (10 s)** — Checklist item + download HTML report.
6. **Close (5 s)** — “Gemma + verification layer; not legal advice.”

**Strongest frame:** Side-by-side requirement quotation and evidence snippet with filename/page.

Record with OBS or similar; embed in DEV post (YouTube/Loom unlisted).
